QWEN LOCAL DEVELOPMENT COMMANDS (WINDOWS POWERSHELL)
==================================================
Run these commands from the Qwen repository root unless stated otherwise.
The local model weights and Python environment are not stored on GitHub.

1. RUN QWEN DIRECTLY IN THE TERMINAL
-----------------------------------
.\qwen-env\Scripts\python.exe .\run_qwen.py

Type 'quit' or 'exit' to end the chat.

2. START THE FASTAPI BACKEND
---------------------------
.\qwen-env\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8000 --workers 1

API: http://127.0.0.1:8000
Leave this PowerShell window running while you use either browser frontend.

3. START THE STANDALONE WEB FRONTEND (SECOND TERMINAL)
----------------------------------------------------
.\qwen-env\Scripts\python.exe -m http.server 5500 --bind 127.0.0.1 --directory web

Open: http://127.0.0.1:5500/

4. OPTIONAL: RUN THE SEPARATE EIFFEL TOWER WEBSITE
-------------------------------------------------
In a new terminal, navigate to the root of your Eiffel Tower website project
(maintained separately, not inside this Qwen repository).

Use your Python interpreter to run:
python -m http.server 5500 --bind 127.0.0.1

AI Guide: http://127.0.0.1:5500/qwen-ai/qwen.html
Use this instead of step 3; both frontends use the same port 5500.
The Qwen backend in step 2 must still be running.

5. OPTIONAL GPU MONITORING
-------------------------
nvidia-smi -lms 500

Press Ctrl+C to stop monitoring.

6. NORMAL SHUTDOWN
------------------
Press Ctrl+C in each running server terminal.

7. CHECK WHETHER SERVERS ARE STILL LISTENING
--------------------------------------------
Get-NetTCPConnection -LocalPort 8000,5500 -State Listen

No matching results means nothing is listening on those ports.
